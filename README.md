# Kollektor

Aplicación web mobile-first para gestionar y explorar una colección personal de discos de vinilo:
qué tengo, qué quiero, cuánto vale y qué me falta.

El modelo gira alrededor de **la edición que posee el usuario** (Artist → Album → Release → CollectionItem),
no del álbum genérico.
